# FFXIV 副本标题制作器

一个完全在浏览器中运行的 FFXIV 风格副本标题制作工具。输入区域名称和副本名称，即可生成透明标题素材；也可以载入自己的背景图片，直接制作完整画面。

> 本项目是非官方粉丝工具，与 Square Enix 无关联。FINAL FANTASY XIV 为其权利人的商标。本项目不包含或分发 Adobe 黑体 Std，也不包含游戏截图、Logo 或其他官方素材。

## 主要功能

- 支持自动识别、中文和 English 三种样式模式，并分别保留两种语言的编辑内容和参数。
- 支持透明标题实时预览，可导出透明 PNG 或白底 JPG，并提供 1×、2×、4× 清晰度。
- 支持载入 PNG、JPG、JPEG、WebP 背景图，调整标题大小和上下位置后导出 JPG 合成图。
- 支持用户在当前浏览器会话中临时载入自己合法持有的 OTF、TTF、WOFF 或 WOFF2 中文字体。
- 字体、背景图片和生成过程均留在浏览器本地，不上传、不保存，不需要账号。
- 对超大图片和标题画布进行尺寸保护，避免超过常见浏览器的安全范围。

## 使用方法

1. 输入上方区域名称和下方副本名称。
2. 使用“自动 / 中文 / English”选择版式；自动模式会在任意一行包含汉字时使用中文方案。
3. 根据需要调整字号；字距、间距、横线和光效位于“更多设置”。
4. 不上传背景图时，导出透明标题 PNG 或白底 JPG。
5. 上传背景图后会自动进入图片合成模式；调整标题大小和上下位置，再导出 JPG。

背景图片与本地字体只存在于当前页面会话中，刷新或关闭页面后会失效。

## 当前字体设计方案

这一节记录当前版本实际采用的字体和光效设计。后续只要字体、排版或金属效果发生变化，应在同一次修改中同步更新本节。

### 标题结构

- 上方为较小的区域名称，下方为较大的副本名称。
- 区域名称下方绘制一条横线，宽度按照区域名称的实际字形边界计算并居中。
- 两行文字按 Unicode 字素逐个测量和绘制，避免拆散组合字符；中英混排时按照字符选择字体。
- 基础金色为 `#be944f`，文字和完整光效会自动紧贴裁切。

### 中文方案

- 默认字体：开源思源黑体（Source Han Sans CN Regular）。
- 可选字体：用户自己合法持有并从本地载入的 Adobe 黑体 Std；文件只注册在浏览器内存中，不会上传或持久化。
- 默认示例：`诺弗兰特 / 末日暗影亚马乌罗提`。
- 默认区域名：32px，字距 `0.10em`。
- 默认副本名：72px，字距 `-0.12em`。
- 区域名到横线 4px，横线到副本名 8px，横线粗细 2px。
- 文字蒙版会收紧半透明边缘，以近似 Photoshop“犀利”的抗锯齿观感。
- 字面以 `#be944f` 为主色，并在每一行内部形成上亮下暗的轻微金色渐变。
- 金属浮雕使用约 5px 的内部高度场和法线计算，模拟 120° 方位、20° 高度的光照及双峰光泽等高线；上半部分高光权重高于下半部分。
- 当前中文版使用中性米金高光、黑色浮雕暗部、深灰贴边描边、轻微内发光以及灰金色外发光。默认外发光强度为 75%。
- 中文暗部刻意避免使用高饱和暖红色，以降低横向笔画下沿出现红线的风险。

### English 方案

- 字体：Cinzel 400 罗马衬线体，不受本地中文字体切换影响。
- 默认示例：`NORVRANDT / AMAUROTA`。
- 默认区域名：38px，字距 `0.38em`。
- 默认副本名：92px，字距 `0`。
- 区域名到横线 5px，横线到副本名 10px，横线粗细 3px。
- 每个英文单词的首字母使用完整字号，其余拉丁字母使用 82% 字号，复现参考标题中较大的首字母和较小的大写字母。
- 英文继续使用独立的经典金色描边、浮雕高光、乘色阴影、内发光和外发光方案；默认外发光强度为 75%。中文版金属参数的调整不会自动套用到英文版。

## 图片合成规则

- 标题始终水平居中，默认中心位于画面高度的 46%。
- 默认副本名字号约为背景图高度的 10.5%，区域名沿用当前语言的上下行字号比例。
- 标题层最大宽度为画面的 78%；过长时会整体等比缩小，不会横向拉伸。
- 标题大小可在 60%–140% 之间调整，上下位置可在画面高度的 30%–70% 之间调整。
- 合成图保持背景图宽高比；超过单边 8192px 或约 1600 万像素时会等比缩小到安全范围。
- 当前图片合成模式只提供 JPG 导出，质量为 95%。

## 本地开发

需要 Node.js 20 或更高版本。

```bash
pnpm install
pnpm dev
```

测试与生产构建：

```bash
pnpm test
pnpm build
```

构建产物位于 `dist/`，可部署到任意静态网站托管服务。
